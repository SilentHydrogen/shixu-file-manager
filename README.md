# 拾序文件管理器

**当前版本：v1.0.0**

拾序是一款面向 HarmonyOS 移动端的智能文件分类整理应用。它围绕“先收纳，再按规则归类”的使用方式设计，帮助用户把散落的文档、图片、音频、作业、项目文件等快速放回合适的位置。

## 功能亮点

- **文件收纳箱**：从系统文件中选择文件，统一导入到应用内进行管理。
- **智能整理**：根据文件名、类型、内容关键字、大小和使用场景，将文件自动归入对应分类。
- **人工确认**：当规则无法明确判断时，保留人工确认流程，避免误分类。
- **自定义分类**：支持创建标签、选择图标和颜色，并同步生成对应整理规则。
- **场景化规则**：内置学生、摄影师、程序员和通用四类使用方式，切换后生成更贴合场景的默认分类与规则。
- **桌面小组件**：提供可实时同步的“最近文件”和“快捷分类”；可从桌面直接打开最近文件、进入标签或添加文件。
- **多类型内容提取**：对文本、图片、Office 文档和 PDF 做基础内容识别，用于辅助分类。
